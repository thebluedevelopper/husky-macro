# 🐕 Husky Macro v5.0
> **Professional Workflow Automation for Windows**

Husky Macro is a premium automation engine designed to handle complex repetitive tasks with elite precision. Unlike simple recorders, Husky offers a full 8-tab suite to record, edit, and chain macros using an advanced sequential scheduler.

### 🚀 Key Capabilities
- **Advanced Scheduler**: Queue multiple macros with custom repetition logic.
- **Micro-Editing**: Tweak coordinates and millisecond delays without re-recording.
- **Smart Organization**: Tag and search through hundreds of macros instantly.
- **Global Control**: Emergency stop (Alt+W) and background hotkeys.
